# Package 059 — CMDB Operational State Framework

Adds Nexus-specific operational metadata to managed CMDB assets:

- Mission and operational role
- Nexus Managed / Customer Managed / Observed responsibility
- Lifecycle stages aligned to mining infrastructure
- Desired and observed operational state
- Health and connectivity
- Audited operational-profile changes
- CMDB object-page dropdowns and edit controls
- Canvas mining labels with live hashrate

The package extends the existing PostgreSQL CMDB. It does not replace live telemetry or reconciliation.
