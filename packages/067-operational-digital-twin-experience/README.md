# Package 067 — Operational Digital Twin Experience

Transforms the CMDB object page from a raw record viewer into an operational-first Digital Twin.

## Highlights
- live object-specific operational metrics
- friendly identity labels and coin metadata
- health, connectivity, telemetry and last-observed panels
- clickable, status-aware relationship cards
- context-aware operations links
- recent operational timeline
- editable CMDB profile retained below the live view
