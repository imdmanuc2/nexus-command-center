# Package 068 — Fleet Operations Center

Transforms the Nexus CMDB overview into a scalable operational fleet console.

## Highlights

- Live fleet KPIs and hashrate summary
- Saved operational views
- Quick filters and fleet search
- Collapsible groups for pools, miners, blockchain nodes, services, and infrastructure
- Rich operational cards with state, hashrate, assignment, lifecycle, and last-observed time
- Incremental “show more” behavior for large groups
- Direct navigation to each object's Digital Twin

Install from `nexus/` with `doctor.sh`, `install.sh`, and `verify.sh`.
